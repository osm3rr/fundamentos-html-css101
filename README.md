# Proyecto: CSS Fundamentals

Este proyecto es una colección de archivos HTML y CSS diseñados para enseñar y practicar los fundamentos de CSS (Cascading Style Sheets). Está orientado a estudiantes o personas que desean aprender a estilizar páginas web utilizando selectores, propiedades y buenas prácticas de CSS.

## Estructura del Proyecto

- `home.html`: Página principal de ejemplo para aplicar estilos CSS.
- `home2.html`: Segunda página de ejemplo para practicar selectores y estilos.
- `home3.html`: Tercera página de ejemplo para ejercicios adicionales.
- `main.css`: Archivo principal de estilos CSS donde se definen los estilos aplicados a las páginas HTML.

## Contenido de `main.css`

El archivo `main.css` incluye ejemplos de:
- **Selectores por etiqueta**: Ejemplo, `body`, `h1`.
- **Selectores por clase**: Ejemplo, `.texto-article`, `.texto-plano`.
- **Selectores por id**: Ejemplo, `#subtitulo`.
- **Selectores combinados y anidados** (comentados): Ejemplo, `div p`, `article p`.
- **Propiedades de color y tipografía**: Uso de `color`, `background-color`, `font-size`, etc.

## Objetivos de Aprendizaje

- Comprender la estructura básica de un archivo CSS.
- Aplicar estilos a elementos HTML usando selectores de etiqueta, clase e id.
- Diferenciar entre selectores simples y combinados.
- Modificar colores, tamaños de fuente y otros estilos visuales.
- Comentar y descomentar reglas CSS para experimentar con diferentes estilos.

## Cómo Usar el Proyecto

1. Abre cualquiera de los archivos HTML (`home.html`, `home2.html`, `home3.html`) en tu navegador web.
2. Modifica el archivo `main.css` para ver cómo cambian los estilos en las páginas.
3. Prueba agregando nuevas reglas CSS o editando las existentes para reforzar tu aprendizaje.
4. Descomenta las reglas CSS comentadas para ver su efecto.

## Ejemplo de Selectores en `main.css`

```css
body {
    background-color: rgb(221, 221, 243);
}

h1 {
    color: red;
}

.texto-article {
    font-size: 30px;
    color: purple;
}

#subtitulo {
    color: aqua;
}
```

## Recomendaciones

- Utiliza un editor de código como VS Code para editar los archivos.
- Usa la función de recarga automática del navegador para ver los cambios en tiempo real.
- Consulta la [documentación oficial de CSS](https://developer.mozilla.org/es/docs/Web/CSS) para profundizar en los conceptos.
